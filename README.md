## 🎨 Design & Aesthetic Highlights

- **Deep Space Theme:** Implements a premium, customized dark mode palette using the modern OKLCH color system (`oklch(0.14 0.03 285)` background, purple accents, and emerald/gold highlights).
- **Glassmorphism & Gradients:** Dynamic cards with border-gradient glows, background grid patterns, and radial landing page gradients.
- **Micro-Animations:** Custom float animations (`animate-float`) and pulsing terminal glows (`animate-pulse-glow`) to deliver a state-of-the-art visual experience.
- **Fluid Responsiveness:** Tailored using standard CSS and Tailwind CSS classes to support flawless desktop, tablet, and mobile views.

## 💻 Key Features

### 1. Interactive Command-Line Terminal

The portfolio features a fully interactive Terminal emulator built from scratch in React & TypeScript. It supports history scrolling (Arrow Up/Down keys), custom prompt boot animations, interactive quick-run action buttons, and direct command inputs:

- `help` — Lists all available CLI options.
- `about` — Brief introduction of Rohit Raj.
- `skills` — Showcases languages, frameworks, and developer tools.
- `projects` — Interactive menu for highlighting projects.
- `experience` — Quick summary of major achievements and career events.
- `contact` — Provides direct email and links to contact details.
- `socials` — Online footprint links (GitHub, LinkedIn, Instagram).
- `clear` — Resets the terminal output display.

### 2. Projects & Achievements Showcase

Organized dynamically, highlighting major projects such as:

- **DBT Setu** — _Smart India Hackathon 2025 Winner_ created for the Ministry of Social Justice & Empowerment to promote Aadhaar-seeded bank account awareness.
- **Grocify** — A clean, aesthetic, and responsive grocery ordering application.
- **CareConnect** — An intuitive patient-doctor appointment scheduler and healthcare platform.
- **Wave** — Real-time peer-to-peer messaging and video call application.
- **Vora** — Music streaming and playlist management application.

## ⚙️ Getting Started & Local Setup

### Prerequisites

Make sure you have **Node.js (v18.0.0 or later)** and **npm** installed on your local development machine.

### Installation & Run

1. Clone the repository to your local system:

   ```bash
   git clone https://github.com/rrit58/Portfolio.git
   cd Portfolio
   ```

2. Navigate to the frontend directory:

   ```bash
   cd frontend
   ```

3. Install project dependencies:

   ```bash
   npm install
   ```

4. Run the local development server:

   ```bash
   npm run dev
   ```

   Open your browser and navigate to `http://localhost:5173/` to view the interactive portfolio.

5. Compile and bundle for production:
   ```bash
   npm run build
   ```
   This compiles TypeScript and builds minimized HTML, JS, and CSS files into the `frontend/dist` directory.

## ✏️ Customization Guide

You can easily adapt this portfolio to your own details by modifying the files inside `frontend/src/data/`:

- **Change Projects list:** Update details in `frontend/src/data/projects.ts` (images are imported from `frontend/src/assets/projects/`).
- **Update Experience & Timelines:** Modify career events or educational history in `frontend/src/data/timelines.ts`.
- **Update Skills/Tools Icons:** Edit the tech stack entries in `frontend/src/data/techStacks.ts`.
- **Change Contact Forms or Social Accounts:** Customize values in `frontend/src/data/socials.ts` and update commands inside the interactive terminal component at `frontend/src/components/InteractiveTerminal.tsx`.
